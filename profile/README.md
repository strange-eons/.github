# Strange Eons

**Create cards, tokens, boards, and other components for tabletop games.**

[Strange Eons](https://strangeeons.org/) is a free, extensible design tool for making custom content for existing games or building a game of your own. It handles layout and typesetting so you can focus on the ideas and artwork.

- **Get started:** [Download Strange Eons](https://strangeeons.org/)
- **Learn:** [User and developer documentation](https://se3docs.cgjennings.ca/)
- **Explore the code:** [Strange Eons source](https://github.com/strange-eons/strange-eons)

Strange Eons supports projects of all sizes, from a single card to a full game. Its built-in scripting tools and plug-in system let you add support for games, component types, and workflows.
